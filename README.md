This website is an advance why to go about skin care. we use AI to scan your skin and in return we give you custom skin care routine. This Will first ask for you to submit a photo from your files or photo album on mobile or as for permission to use your camera to submit a photo, The photo will then be taken and sent to the AI to scan your face to give you your custom results!

## Getting Started

### Prerequisites

* **Node.js:** `v20.19.41` (or any Node `v20.19+` / `v22` LTS)
  * *If you use [nvm](https://github.com) (or [nvm-windows](https://github.com)), run:*
    ```bash
    nvm install 20.19.41
    nvm use 20.19.41
    ```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd giovanni-skintric-internship
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open the local URL shown in your terminal (usually [http://localhost:5173](http://localhost:5173)) to view the app, or check out the live deployment at [giovanni-skintric-internship.vercel.app](https://vercel.app).
